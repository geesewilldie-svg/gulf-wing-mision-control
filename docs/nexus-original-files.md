# Original files behind current file stars

The expanded galaxy reader and Ask Nexus indexed-file response offer separate **Open original PDF** / **Open original text** and **Download original file** controls. The extracted preview and its part navigation remain available. Browser opening is an explicit new-tab link, not model/browser automation; PDF rendering depends on the device/browser. XLSX originals download for the owner's chosen viewer. Markdown/text is served as plain text, never executable HTML. Links are relative to the paired app origin and work on the laptop or paired phone. Keyboard focus in the expanded reader includes the new links.

## Resource boundary

`GET /api/sync/files/original?id=<id>&hash=<hash>` requires the existing controller session, same-origin checks and current selected index. It accepts no path/filename argument. A new-tab request rechecks folder configuration, index identity, file identity/link/junction rules, size/mtime and exact SHA-256. Invalid, stale, unavailable or revoked sources fail closed; a copied URL without a paired controller session is insufficient. This reads only the requested original, not every selected source. No file is edited and no worker, provider or native application command is started.

Current formats are already-indexed PDF, Markdown/text and XLSX. Existing per-file reads are capped at 2 MB. Files absent from the index, scanned PDFs with no extractable sections, unsupported images/media, whole-drive browsing and arbitrary native opening are not added by this route. `download=1` forces attachment; XLSX is always an attachment. No byte-range serving or caching is claimed. The route returns full original bytes with fixed content types, UTF-8 encoded download filenames, `no-store`, `nosniff`, same-origin resource policy and no-referrer headers. Direct browser text viewing preserves original bytes but encoding/rendering can depend on browser support; downloads remain byte-for-byte copies.

Delivering a file is not evidence that a browser successfully rendered it, that all PDF elements were extracted, that workbook formulas were recalculated, or that any business claims in it are true. The source map still represents a selected-index subset, not every drive or file on the host. Opening on a phone displays/downloads laptop-hosted content; it does not launch an app on the laptop or grant access to the phone's own storage.
