# Fish Audio evaluation — disabled pending API and voice-rights review

Review date: 2026-11-06. Product direction: Nexus may become a subscription or client-licensed business platform. A personal audition is not commercial product clearance. No Fish SDK, model weights, API key, subscription or live adapter has been installed or enabled by this review.

## Evidence that was accessible

Official `fishaudio/fish-speech` repository, reviewed at commit `0f8a12e8a651062fdee9c33a894bdccd3a8513f1` (2026-10-30). The README links the Fish Audio product website. Only source/documentation was read in a temporary review checkout; no Fish code was executed or copied into Nexus.

- [Install requirements](https://github.com/fishaudio/fish-speech/blob/0f8a12e8a651062fdee9c33a894bdccd3a8513f1/docs/en/install.md): Drama 3 specifies at least 48 GB GPU memory (FP8); S2-Pro specifies at least 24 GB GPU memory for the documented GPU route. S2-Pro also has a CPU option. The documented systems are Linux/WSL. These are upstream specifications, not a measured benchmark of Nexus or this laptop.
- [Model overview](https://github.com/fishaudio/fish-speech/blob/0f8a12e8a651062fdee9c33a894bdccd3a8513f1/README.md): Drama 3 is listed as 35B-A3B and S2-Pro as 4B. The README explicitly says S2-Pro weights remain under a separate Fish Audio Research License; source-code permission must not be substituted for a model-weight license.
- [Community license v1.0](https://github.com/fishaudio/fish-speech/blob/0f8a12e8a651062fdee9c33a894bdccd3a8513f1/LICENSE), last updated 2026-10-13: Section III(a) permits specified commercial use while aggregate annual gross revenue of the licensee and affiliates is below USD 500,000, subject to the full agreement. This is a revenue condition, not an API price or blanket commercial clearance. Client/on-premises installations have additional customer-revenue conditions. Section III(b) requires notice and a transition to a separate agreement upon reaching the threshold, subject to its exact terms.
- Section III(c) requires a separate written agreement for the defined Hosted Service regardless of revenue. It expressly excludes delivering speech for content generated by one's own product, including an assistant's spoken replies, from that definition. That distinction may fit a Nexus assistant feature, but not necessarily a general customer-facing TTS/voice-cloning service. The rest of the license still applies.
- Section IV(a) includes distribution notices and prominent “Built with Fish Audio” attribution for covered products/services. Section IV(b) includes rights/consent requirements for identifiable voices and downstream restrictions. Section IV(c)(iii) addresses ownership of generated output as between the licensee and Fish Audio, to the extent permitted by law; it does not supply missing third-party voice rights.

These findings concern the reviewed self-hosting materials and version, not the hosted API's service contract. The agreement distinguishes separately licensed weights. Review the exact license bundled with any chosen model; do not assume this version covers all old models, quantizations or community voice packs.

## Current laptop recommendation

Operator-reported hardware: ASUS VivoBook X532FLC/S532FL, Core i5-10210U, 8 GB system RAM, NVIDIA MX250 and Intel UHD graphics. Do not install the current full Fish models as Nexus's real-time local voice on this laptop. The documented GPU targets are far above this hardware; CPU availability alone does not establish usable speed or adequate memory while Windows, Whisper, Ollama and Nexus run together. No unofficial low-memory build has been evaluated.

A hosted speech API could be used from this laptop because generation occurs on the provider's servers, but requires internet access and a separately authorized account. It discloses the text sent for speech to that provider. There is no measured latency comparison yet, and no claim that it is cheaper or faster than Kokoro in this deployment.

## Unverified; blocks activation

The Fish Audio product, pricing, API documentation and legal pages could not be accessed from this environment (proxy returned 403). Therefore **current API pricing, billing units, minimum charges, streaming entitlement, API commercial/end-customer rights, retention/training practices and current hosted service terms are not verified**. No API price is quoted. Web-app credits/subscriptions must not be assumed to include API credits or commercial redistribution rights.

The operator selected a preferred voice in the web app, but its name/share link/model ID has not been provided. Voice-specific rights and API availability therefore remain unverified. A publicly selectable or excellent-sounding voice is not automatically approved for a commercial subscription product.

Before activation, obtain current official API pricing/terms and the exact voice's permitted uses; check whether its owner permits commercial assistant output for customers, including any limits or attribution. Clarify API-backed subscription features, output distribution, customer usage and any sublicensing/resale restrictions against the intended architecture. Do not contact Fish or agree to paid terms on the operator's behalf without explicit instructions. Do not paste keys into chat.

## Commercial product architecture decision

Keep speech providers interchangeable. Retain an independently reviewed local fallback and keep Fish disabled until the above review is complete. A future implementation should put credentials on the server, enforce per-tenant identity/usage/budgets, and keep provider/voice entitlement records. Do not bundle Fish weights/code or market Nexus as an unrestricted speech-generation API based solely on this review.

The whole product also needs a dependency/model/voice-license inventory and required notices before packaging or sale, including existing Kokoro/Piper assets. The current laptop prototype uses shared trusted-controller pairing and is not yet a tenant-isolated hosted subscription product. Commercial readiness additionally requires production identity/HTTPS, tenant isolation, customer terms/privacy and a billing/operations design. This document preserves that product direction; it is not a statement that those controls or all license reviews are complete.

Next decision: preserve the selected voice details; verify hosted API and voice-specific terms; estimate an explicit trial usage cap from verified prices; then authorize a small, public-text latency/quality test. No inference, paid API call or commercial deployment occurred during this review.
