# Gemini Public: unpaid, non-sensitive questions only

The operator chose to keep Gemini on the free tier and consider paid use later. Google unpaid-service terms pasted by the operator say Google can use submitted content and responses for service/model improvement and human review, and explicitly prohibit submitting sensitive, confidential or personal information. The operator is in Florida; the pasted EEA/Switzerland/UK exception does not cover that location. Terms/pricing excerpts were supplied from Google by the operator because this coding environment could not retrieve the live terms page.

This increment adds a separate **Gemini Public** tab. The existing Ask Nexus business workflow stays available with the local model. The public endpoint constructs a fresh request from one explicitly confirmed question; it does not reuse the business question box, voice input, file search, Google Drive snapshots, calendar data, owner memory or history. It does not execute tools, search Google, use grounding or compare providers.

## Install and connect on the Windows laptop

1. Pull this update, stop the project's existing Next process, run `npm.cmd run build`, then `Start-Nexus.cmd` as usual.
2. Keep the Google project on **Free tier** with billing unchanged. Open the key privately in Google AI Studio; do not paste it into chat or a PowerShell command line.
3. Run `.\Setup-Nexus-Gemini.cmd`. Paste the key into the hidden native prompt. Setup reads Google's model metadata at the fixed Generative Language API endpoint, using the key in a header. It sends no question or document for generation.
4. Choose an available supported model by number; Enter chooses the first. The preference list starts with `gemini-3.5-flash-lite`, then supported earlier Flash-Lite/Flash alternatives advertised with a free tier. A model must be returned by the key's model list and support `generateContent`. Paid-only/unlisted models are not automatically substituted. The list of allowed names does not establish current quotas, availability or future pricing; verify those in AI Studio.
5. The key is saved using Windows current-user DPAPI encryption in the ignored private `.gulf-wing/gemini-public.json` (or `GW_SYNC_DATA_DIR`). The running Nexus server must use that same Windows account. No plaintext key is stored by this setup. The setup asks for the key as secure input and passes transient key data on stdin for model discovery, not as process arguments or shell-history text. Do not share the private configuration or Windows profile.
6. No server restart is required after setup: open **http://localhost:3000/nexus → Gemini Public**. Use a harmless question such as “Explain the difference between revenue and profit in general.” Check the explicit public-information confirmation, then **Ask Gemini Public**.
7. The checkbox resets for each question and when the text changes. Answers are displayed only in this panel and are not automatically added to private conversations, owner memory or speech playback. Stop cancels the client request; Google might already have received a submitted question.

The software cannot determine whether arbitrary text you type/paste is private. Do not put customer names, personal details, private company figures, credentials or document excerpts into this public box. The automatic separation of saved context is not a sensitive-data detector.

## Boundaries enforced on the server

- Controller authorization and same-origin POST/DELETE protection. Display-only devices cannot invoke or inspect this setup.
- Only `question` (up to 2,000 characters) and `confirmedPublic: true` are accepted. Extra fields—including sources, history, memory, attachments or a system override—are rejected before generation.
- The provider payload contains a fixed public-only system instruction, one user question and an output limit of 1,024 tokens. No retrieval or private service module supplies context to it. Internal thought parts are not displayed as user answers. Empty answers and provider failures are reported without silently using another model.
- Once the `gemini-public.json` policy file exists, Gemini is excluded from regular private routing, Auto and Compare, even if older environment keys/configuration exist. Direct private-context calls are also blocked. Disabled, corrupt or unreadable public-policy configuration does not silently reopen that path. Other providers retain their existing controls; the public setup does not enable them.
- One in-flight public request and a persisted allowance of at most **10 generation attempts per UTC day**, separate from any general external-provider allowance. Failed provider attempts consume an allowance; there are no automatic retries or fallback. Re-running setup/model selection does not reset it. Corrupt allowance data stops requests. Local key unlock occurs before reserving an attempt; cancellation/disable is rechecked before sending.
- Fixed HTTPS Google endpoints, API key in a header (never URL), disabled redirects, bounded model/output responses and a generation timeout. No secret or raw provider error body is returned in browser status. Events record provider/state/timing, not prompt text.

Model generation is free only subject to the actual Google project tier/model/quotas. This implementation does not inspect, enable or disable Cloud Billing. **Ten requests is not a dollar spending cap.** If billing is later enabled outside Nexus, pricing can apply while this local policy remains public-only. No paid-only or quota-exhaustion fallback is enabled.

## Disable, recovery and later paid use

Use **Disable public Gemini** in the panel or `.\Disable-Nexus-Gemini.cmd` on the laptop. This stops future public requests and preserves the public-only policy; private-context Gemini stays blocked. Re-run setup to change/re-enable a valid model/key. Existing allowance is retained. If DPAPI unlock fails, run setup under the same Windows user that runs Nexus. Model/key/network failures are not repaired by printing credentials. API-key revocation is managed separately in Google AI Studio.

DPAPI encryption is tied to the Windows user/profile, not a portable multi-tenant credential vault. The encrypted key must be reconfigured when moving Nexus to another user/device. A fixed native PowerShell subprocess performs DPAPI unlock; ciphertext travels on stdin and plaintext is captured privately by Node, never used as a shell command. No arbitrary PowerShell execution service is exposed by this feature.

A future paid/private-context Gemini setup is a separate explicit upgrade: verify an active billing project, current paid data-use terms/prices, a suitable model, bounded usage and per-question private sharing before replacing the public-only policy. Enabling billing alone does not lift this policy. The operator-provided paid terms state prompts/responses are not used to improve Google products but still permit limited abuse-prevention/legal logging; they do not promise zero retention. Selling Nexus still requires provider terms, client consent, account isolation and appropriate secret management. This increment does not establish commercial launch readiness.

References: [Gemini API terms](https://ai.google.dev/gemini-api/terms), [pricing](https://ai.google.dev/gemini-api/docs/pricing), [models API](https://ai.google.dev/api/models). The native model list and public generation test remain laptop acceptance steps; the coding environment uses synthetic credentials/providers only.

## Setup diagnostics and Windows input compatibility

The setup helper now returns a structured success/error envelope on stdout so PowerShell can show a safe diagnosis even when the helper exits nonzero. It recognizes UTF-8 BOM and UTF-16LE BOM input. Native setup trims surrounding copied whitespace before both model listing and DPAPI encryption; quotes, code examples and other invalid key formats are rejected. No raw key, key length/value, provider message, provider metadata or unknown network exception is printed.

Safe codes distinguish `KEY_FORMAT`, `KEY_REJECTED`, `API_DISABLED`, `KEY_RESTRICTION`, `FREE_QUOTA_UNAVAILABLE`, `GOOGLE_ACCESS_DENIED`, `BILLING_REQUIRED_BY_PROVIDER`, network/DNS/TLS/timeouts, malformed/oversized lists and `NO_SUPPORTED_MODEL`. The last code reports only a bounded model count, not arbitrary provider strings. Error reasons are extracted from a bounded response using an explicit allowlist; HTTP status is safe numeric metadata. A billing-required diagnosis instructs the operator to stop and leave billing unchanged. It never changes the model, permissions, billing or request allowance automatically.

If setup stops, share only the displayed diagnostic lines. The native laptop cause is not established until those lines are available. Existing configuration is preserved on failure. These are installer-only changes: pull the update and rerun `Setup-Nexus-Gemini.cmd`; an already running Nexus build does not need restarting or rebuilding for the diagnostic update. The public request/policy schema and runtime isolation are unchanged.

Validation of the diagnostic update: eight Node tests passed, including the actual CLI success/error envelopes, Windows BOM input, secret canaries in provider messages/metadata/exceptions, unchanged old configuration on failure, known HTTP/network classifications and allowlist-only model selection. Eight existing public privacy tests and TypeScript checking passed. CI also runs the Node diagnostic tests.
