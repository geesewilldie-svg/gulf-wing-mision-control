# Storage objects in the original spiral

Memory Galaxy now offers **Knowledge stars** and **Storage galaxy**. Knowledge stars retain the current indexed-file behavior. Storage galaxy reuses the original animated spiral and the selected-location resource service. It opens the existing explorer automatically and shows the current host's locally selected locations, then one directory page at a time. No connecting graph lines or inferred relationships are added.

Drive objects have a ringed marker, folders have a small folder-colored marker, and files retain bright stars. Only actual returned roots/entries become selectable objects; ambient background stars remain decorative. Unavailable roots are disabled and remain described in the list. The overview does not imply undiscovered drives or all-computer coverage. Browse-only locations must still be selected locally with `Setup-Nexus-Storage.cmd`; knowledge-folder grants remain independent.

First selection focuses/zooms a resource without reading content. Enter drive/folder, or activating the centered object again, fetches that directory's metadata. File selection followed by **Show file actions** opens a large dialog with listed metadata and the existing original-file controls; an optional indexed-preview button is supplied only for a current cached reference. The actual read/download happens on the selected control, with server-side access/version checks. Unsupported or oversized originals show an explicit unavailable state. No hash is invented for an unindexed file; the renderer's metadata objects do not provide authority to read it.

Breadcrumbs, Back, page controls, page-name filtering and the conventional list alternative remain available. The spiral contains only the current directory page (at most fifty entries), not a whole-drive scan. Neighborhoods describe entries on that page or the selected-location list, not semantic or physical file containment. Focused neighborhoods can show fewer nearby objects; the page list remains available. Existing inspection/time/depth/path limits and omitted/partial counts still apply.

Zoom, unrestricted two-axis rotation, pause, reduced motion and keyboard controls reuse the shared visual. Names are hidden until hover, focus or selection; Show all file names is optional. Direct Fullscreen controls request native fullscreen and keep an expanded fallback when unavailable. Expanded view retains the mounted navigator, current path, focused object and file state. Changing between Knowledge stars and Storage galaxy resets the folder navigator; fullscreen expansion does not. Changing a folder/page intentionally starts a new resource neighborhood. Private source access remains controller-only; an access failure clears private browser state through the existing shared handler.

Validation uses real disposable browse grants and files: drive → folder → file, keyboard focus activation, zero read on focus, full-screen expansion/collapse, a browser-decoded PNG, unsupported-file actions, breadcrumbs and removed-grant reload. Desktop and phone layout checks run alongside existing knowledge Galaxy and file-browser regressions. This does not claim native phone storage, network/Google Drive hydration, arbitrary native applications or unrestricted whole-computer access.
