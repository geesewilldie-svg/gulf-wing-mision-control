# User-provided design references

These five images were supplied as visual references for this phase. They are documentation references, not shipped application UI, backgrounds, brand assets, or a claim of affiliation.

- `command-workshop.jpg`: independent screens, panoramic command workspace, cyan illumination.
- `holographic-workbench.jpg`: layered technical information and fine luminous outlines.
- `cyan-radial-hud.jpg`: concentric rings, segmented arcs, calibration marks.
- `reactor-command-layout.jpg`: a clear central energy core and satellite readouts.
- `blue-orbital-console.jpg`: cool blue highlights, orbit geometry, dense but organized information.

Gulf Wing uses original programmatic visualization geometry and its own copy/data. The visual direction emphasizes a radial core, restrained cyan light, transparent-looking dark panels, accessible HTML controls, Android phone operation, and Windows multi-monitor presentation. Hardware-looking gauges must describe actual demo workspace data rather than inventing CPU, weather, or device telemetry.
