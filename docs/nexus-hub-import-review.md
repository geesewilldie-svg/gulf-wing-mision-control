# Read-only archive-to-runtime import review

Connections → Models and tools → Local model archive offers **Review runtime import** for a recorded completed transfer whose current file size matches the inspected receipt. This is a pre-import evidence review. It does not upload weights, create an Ollama model, reserve disk/RAM, start inference or change selection.

The controller-only, same-origin endpoint accepts exactly `action: import-review`, a fixed archive slot and the inspected receipt SHA-256. Caller paths, URLs, model aliases and runtime options are rejected. The operation reads only the fixed local Ollama `/api/version` endpoint (GET, no credentials or redirects, 5-second wait, 20 KB response bound). A missing/invalid version stays unavailable; a reported version does not establish create/import compatibility. No Hub, account or hosted inference request is made.

The source review reuses the archive's single-check admission and 10-minute full-file hashing bound. It requires a recorded verified transfer, exact inspected receipt digest, current file-size/SHA-256 agreement and safe source/directory identity. Bounded GGUF metadata inspection runs inside the successful hash operation's final file/receipt identity fence. This catches same-size edits outside the parsed metadata as well as replacement/receipt changes. Unfinished or uncertain transfer outcomes are not silently promoted by this review. The source model and receipt stay unchanged.

Results combine the exact source identity, recorded license, current local hash-check time, declared GGUF metadata, runtime-reported version and a current Nexus-host total/free RAM snapshot. Metadata remains declared/untrusted and limited to the parser's existing coverage. File size is not a model's working-memory requirement; free RAM does not measure VRAM or prove fit. Host RAM means the server hosting Nexus, not the phone viewing it. Export saves only the displayed JSON review.

The review explicitly reports remaining blockers: Ollama-managed destination and capacity are not yet bound; tensor layout/runtime support is not validated; working context/hardware fit and inference readiness are untested; recorded license terms still need intended-use review. Partial metadata, unknown architecture or unavailable runtime add their own blockers. Import remains unavailable in this phase. The future write adapter must establish the actual runtime storage location/capacity and fresh source/license identity before any explicit import action; archive-volume capacity cannot substitute for runtime-volume capacity.

This is a snapshot, not a continuing integrity guarantee, authentication of editable local receipts or an import authorization token. Cancelling/unmounting clears the page result and never creates runtime state. Native Windows acceptance and actual model import remain separate work.
