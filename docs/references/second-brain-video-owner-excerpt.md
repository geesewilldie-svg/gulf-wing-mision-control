## Factual qualification

The transcript's description of Obsidian as “open source” is inaccurate: Obsidian is proprietary software; its Markdown notes are portable plain-text files. A memory adapter supplies selected context to a model; it does not train that model or guarantee complete understanding. The video's claim that all agents see updates is an architectural goal for Nexus, not proof that our current adapters already share everything.
