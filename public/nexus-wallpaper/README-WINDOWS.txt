NEXUS - NEURAL FIELD / LIVE WINDOWS WALLPAPER

Original animated globe, neural firing paths and holographic HUD.
No accounts, paid services, internet, microphone, local server or API keys required.
The named agent markers and pulses are decorative; they are not live agent activity.

INSTALL ON WINDOWS
1. Install Lively Wallpaper from the Microsoft Store or its official project:
   https://www.rocksdanister.com/lively/
2. Save Nexus-Neural-Field.zip somewhere on your laptop.
3. Open Lively Wallpaper, select Add Wallpaper, and choose/drag the ZIP into Lively.
4. If ZIP import is unavailable: right-click the ZIP, choose Extract All, then in
   Lively choose Add Wallpaper > Choose a file and select the extracted index.html.
5. Select the wallpaper in Lively's library and choose your laptop display.

The supplied HTML also opens as a normal webpage for preview. Opening it in a
browser alone does not put it behind Windows desktop icons; Lively handles that.
Do not set the localhost preview URL in Lively when you want independent operation.
Use the extracted index.html or imported ZIP so Mission Control can be stopped.

YOUR ASUS LAPTOP
Start with the main display only. In Lively settings, enable pausing when a
fullscreen app is active and while on battery; labels vary by installed version.
For multiple monitors, use Lively's display selector to choose a single display,
duplicate, or span. Try ScreenPad separately before applying it to all displays.
The globe is limited to 24 frames per second and about 2.6 million drawing pixels;
its text overlays remain sharp at the actual screen resolution.
Windows' Reduce motion preference starts the animation paused.
Use Pause motion or Hide panels in the lower left during preview. In wallpaper
mode, Lively's interaction settings determine whether clicks reach those controls.

The wallpaper has no voice assistant and never records your microphone. Your
existing Nexus assistant runs separately through Mission Control/Nexus Voice.

UNINSTALL
Choose another wallpaper in Lively or exit Lively.
Actual Lively/Windows/ScreenPad acceptance must be checked on your laptop.
